# AI HR Recruiter System

An AI-powered HR recruitment system designed to assist recruiters in screening resumes, analyzing candidate profiles, and improving the hiring process using machine learning and natural language processing techniques.

## Developer

**Abdul Ahad**

## Project Overview

The AI HR Recruiter System helps automate parts of the recruitment workflow by analyzing candidate information and matching it with job requirements. The system can be useful for resume screening, candidate ranking, skill extraction, and HR decision support.

## Features

- Resume screening
- Candidate profile analysis
- Skill extraction
- Job-candidate matching
- Machine learning based prediction
- User-friendly interface
- Faster and more efficient recruitment process

## Technologies Used

- Python
- Machine Learning
- Natural Language Processing
- Large language Models
- Pandas
- NumPy
- Scikit-learn
- Streamlit / Flask
- Git & GitHub
